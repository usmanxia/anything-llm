# AnythingLLM Desktop Module

This directory contains a minimal Electron wrapper for running the AnythingLLM frontend as a desktop application.

## Development

1. Build the frontend:
   ```sh
   yarn prod:frontend
   ```
2. Start the desktop app:
   ```sh
   cd desktop && yarn start
   ```
   Set `ANYTHING_LLM_DEV=1` to load the dev server instead of the built files.

## Packaging

```sh
cd desktop && yarn package
```

The build artifacts will be placed in the `dist` directory generated by `electron-builder`.
