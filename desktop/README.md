# AnythingLLM Desktop Module

This directory contains an Electron wrapper that bundles the AnythingLLM server,
collector, and frontend into a single desktop application.

## Development

1. Build the frontend and move the build output so the server can serve it:
   ```sh
   yarn prod:frontend
   rm -rf server/public
   cp -r frontend/dist server/public
   ```
2. Start the desktop app (this will launch the server and collector processes internally):
   ```sh
   cd desktop && yarn start
   ```
   Set `ANYTHING_LLM_DEV=1` to load the frontend dev server instead of the bundled files.

## Packaging

1. Build the frontend and copy to `server/public` as shown above.
2. Package the desktop app:

   ```sh
   cd desktop && yarn package
   ```

The build artifacts will be placed in the `dist` directory generated by `electron-builder`.
